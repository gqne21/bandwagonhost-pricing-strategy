## How the promo code system actually works

BandwagonHost discount codes are **recurring discounts**. When you apply a valid code at checkout, the discount rate gets recorded against your account and every future renewal bill is calculated at the discounted price automatically — you never re-enter the code. A 6.77% code on the $169.99/year CN2 GIA-E plan works out to roughly $11.50 saved per year, every year, for as long as you keep the plan.

Three rules from the official checkout flow and 2026 community documentation:

1. **One code per order.** Codes don't stack with each other, and there's no evidence they stack with limited-edition pricing.
2. **Validate before paying.** Paste the code into the "Promotional Code" box on the cart page, click Validate Code, and confirm the price refreshes. If it shows "Invalid," the most common cause is an expired code; typos and stray spaces are the runner-up.
3. **Plan changes can reset things.** Upgrading or modifying a plan may require the discount to be reapplied — worth remembering before you click upgrade on a plan you bought with a code.

The recurring mechanic also explains why old codes have such a devoted following: anyone who applied `BWHCGLUKKB` before November 2025 kept their ~6.78% discount on renewals even after the code itself died. New buyers today can't replicate that without a new code appearing.
